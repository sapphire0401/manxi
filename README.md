# 正念冥想网页原型

> 项目名暂定慢息。

这是一个面向日常放松与正念练习场景的移动端网页原型。项目从“打开后可以立刻开始练习”出发，探索冥想计时、自然声音、每日灵感和习惯记录如何用简洁、安静的界面串联起来。

**当前版本是可交互网页原型，微信小程序开发暂在审核中。** 练习记录和偏好保存在当前浏览器中，暂时没有账号系统或云端同步。

## 功能

- **冥想计时**：首页可选择练习时长；进入练习时使用呼吸节奏动效和柔和的页面过渡。
- **成长时长**：默认跟随累计练习天数变化；累计练习满 7 天后默认时长调整为 10 分钟，也可以在“我的”中固定为 5、10 或 15 分钟。
- **自然声音**：内置森林雨声和狭山细雨，可分别播放、调节音量或叠加混播；面板收起后声音会继续播放。
- **每日灵感**：展示每日一句和一条正念/心理学小知识。当前内容以内置列表轮换，不连接内容管理服务。
- **练习记录**：记录练习日期与时长，展示最近 28 天日历、连续练习天数和累计时长；练习满 7 个不同日期可解锁睡前练习卡片。
- **风景背景**：首页可轮换风景图；冥想界面根据背景图片的主色生成配色。也可在背景图库中添加图片。

## 技术

- HTML、CSS、原生 JavaScript
- `localStorage`：练习记录、时长偏好
- IndexedDB：浏览器中的自定义背景图片
- Canvas：提取背景图片主色
- HTML Audio：自然声音播放与混播

项目不依赖前端框架或构建工具。

## 本地预览

建议用本地静态服务器预览，以便浏览器正确读取图片、音频等相对路径资源。可以在 VS Code 中使用 Live Server 打开 `man-xi-prototype.html`，或使用其他静态文件服务器将 `outputs` 目录作为站点根目录。

核心预览文件：

```text
man-xi-prototype.html
```

声音与背景素材路径由 HTML 中的相对路径引用，请保留 `audio/` 和 `backgrounds/` 目录结构。

## 文件结构

```text
.
├── README.md
├── man-xi-prototype.html              # 当前主原型
├── man-xi-daily-inspiration-audio.html # 与主原型同步的版本
├── audio/
│   ├── forest-rain.mp3
│   └── sayama-rain.mp3
└── backgrounds/
    ├── forest-stream.jpg
    ├── snowy-mountain.jpg
    └── starlight-water.jpg
```

目录中还保留了背景、字体、打卡和声音混合等阶段性 HTML 版本，供回看设计迭代；体验当前功能时优先打开主原型。

## 当前限制与后续方向

- 浏览器关闭或页面被系统回收后，网页音频不能保证继续播放；微信小程序后台音频尚未接入。
- 数据只保存在本机浏览器，清除浏览器数据或更换设备后不会同步。
- 后续计划包括迁移至微信小程序、接入正式音频资源与后台播放，并完善内容管理和云端数据存储。
